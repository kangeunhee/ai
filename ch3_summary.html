Chapter 03

프롬프트 엔지니어링 기술 기초 및 핵심 용어 총정리

프롬프트 엔지니어링의 개념적 정의와 역사적 배경, 인공지능이 언어를 이해하고 생성하는 자연어 기술(NLU, NLG), 그리고 고품질 답변을 도출하기 위한 프롬프트 작성의 기본 원칙(역할 부여, 명확한 지시, 제약 조건 등)을 상세히 정리했습니다.

Part 01

프롬프트 엔지니어링의 개념 및 역사

프롬프트 엔지니어링 (Prompt Engineering)

인공지능 모델이 가장 정확하고 유용한 결과물을 생성할 수 있도록 최적의 명령어와 문맥 구조(프롬프트)를 설계하고 최적화하는 기술 및 방법론입니다.

인컨텍스트 러닝 (In-Context Learning)

모델의 가중치를 직접 수정하지 않고, 입력 프롬프트 내에 제공된 설명이나 예시만으로 모델이 새로운 태스크를 즉석에서 학습하고 수행하게 만드는 특성입니다.

토큰 기반 인터페이스 (Token-based Interface)

초기의 복잡한 프로그래밍 언어나 API 명령어 입력 방식에서 벗어나, 인간의 자연어로 소통하며 AI를 제어할 수 있게 된 대화형 인터페이스 패러다임입니다.

프롬프트 인지 패러다임 전환

과거 머신러닝 모델 구축을 위해 방대한 코딩과 모델 구조 설계가 중심이던 시대에서, 정교한 질문과 지시문 구성이 성능을 좌우하는 프롬프트 중심 시대로의 패러다임 변화를 의미합니다.

Part 02

생성 AI를 위한 자연어 기술 이해

자연어 처리 (NLP, Natural Language Processing)

인간이 사용하는 일상적인 언어를 컴퓨터가 분석하고 이해하며 처리할 수 있도록 하는 인공지능의 핵심 기술 분야입니다.

NLU (자연어 이해, Natural Language Understanding)

인간이 입력한 텍스트의 문법적 구조, 단어 간 관계, 숨겨진 의미와 의도(Intent)를 컴퓨터가 정확히 파악하고 해석하는 기술 영역입니다.

NLG (자연어 생성, Natural Language Generation)

컴퓨터가 분석된 데이터를 바탕으로 문맥에 맞는 자연스럽고 유창한 문장 형태의 텍스트 결과물을 스스로 조합하여 출력하는 기술 영역입니다.

시의성과 모호성 처리 (Ambiguity Resolution)

다의어나 문맥에 따라 뜻이 달라지는 표현 등 인간 언어의 고유한 모호성을 LLM이 문맥적 확률에 기반하여 올바르게 해석해 내는 능력입니다.

Part 03

프롬프트 작성의 기본 원칙

역할 부여 (Role Prompting)

AI에게 특정한 전문가나 페르소나(예: 법률 자문가, 수석 마케터 등)의 신분을 부여하여 해당 전문 분야에 알맞은 어조와 깊이 있는 답변을 이끌어내는 원칙입니다.

명확한 지시 (Clear Instruction)

모호하고 추상적인 표현을 배제하고, AI가 수행해야 할 작업의 목표와 행동 요령을 구체적이고 직관적인 동사로 지시하는 원칙입니다.

맥락 제공 (Context Provision)

작업이 진행되는 배경, 대상 타겟, 목적 등 구체적인 상황 정보를 함께 제공하여 AI가 상황에 꼭 맞는 맞춤형 답변을 생성하도록 돕는 원칙입니다.

제약 조건 설정 (Constraints)

응답의 최대 글자 수, 형식(불렛포인트 등), 포함하거나 배제해야 할 키워드 등을 미리 제한하여 원하는 형태의 결과물을 정확히 얻어내는 원칙입니다.

출력 형식 지정 (Output Formatting)

결과물을 표(Table), 마크다운, JSON, 번호 매기기 등 특정한 구조나 포맷으로 출력하도록 사전에 명시하는 작성 기법입니다.

긍정형 지시 (Positive Instruction)

'~하지 마라'는 부정적 제약보다 '~한 방식으로 작성하라'는 긍정적인 지시문을 사용하는 것이 AI의 오류를 줄이고 정확도를 높이는 작성 원칙입니다.
