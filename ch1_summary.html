Chapter 01

인공지능 기초 이론 및 핵심 용어 총정리

인공지능의 역사적 변천 과정부터 주요 머신러닝·딥러닝 알고리즘, 그리고 혼동 행렬 기반의 성능 평가 지표(정밀도, 재현율, F1 스코어 등)까지 시험에 출제되는 모든 개념을 상세히 정리했습니다.

Part 01

인공지능의 역사와 핵심 알고리즘 용어

인공지능 (AI, Artificial Intelligence)

인간의 학습 능력, 추론 능력, 지각 능력 등을 컴퓨터 프로그램으로 구현하여 지능적인 작업을 수행할 수 있도록 만든 기술 및 연구 분야입니다. 1956년 다트머스 회의에서 처음 공식 용어로 채택되었습니다.

다트머스 회의 (Dartmouth Workshop, 1956)

존 매카시, 마빈 민스키, 클로드 샤논 등의 학자들이 모여 현대 인공지능 연구의 출발점이 된 역사적인 학술회의로, '인공지능'이라는 용어가 공식적으로 탄생한 계기가 되었습니다.

AI 윈터 (AI Winter, 인공지능의 겨울)

초기 인공지능 연구에 대한 과도한 기대와 달리 컴퓨터의 연산 능력 한계, 데이터 부족 등으로 인해 가시적인 성과를 내지 못하면서 정부 지원과 연구 투자가 급감했던 침체기를 뜻합니다.

머신러닝 (Machine Learning, 기계학습)

컴퓨터가 명시적인 규칙을 일일이 코딩하지 않고, 대규모 데이터를 통해 스스로 패턴을 학습하여 예측이나 분류 등의 작업을 수행하는 인공지능의 하위 영역입니다.

지도 학습 (Supervised Learning)

입력 데이터(Features)와 그에 대응하는 정답(Label, Target)을 함께 제공하여 모델이 데이터와 정답 간의 관계를 학습하도록 유도하는 머신러닝 방식입니다.

비지도 학습 (Unsupervised Learning)

정답(Label)이 주어지지 않은 순수 데이터만을 활용하여, 모델이 데이터 스스로의 내재된 구조, 군집(Cluster), 패턴 등을 찾아내도록 하는 학습 방식입니다.

강화 학습 (Reinforcement Learning)

에이전트(Agent)가 환경(Environment)과 상호작용하며 특정 행동을 수행하고, 그 결과에 따른 보상(Reward)을 최대화하거나 벌칙을 최소화하는 방향으로 최적의 정책을 찾아가는 학습 방식입니다.

퍼셉트론 (Perceptron)

프랑크 로젠블랫이 고안한 인공신경망의 가장 기초적인 단위(단층 신경망)로, 여러 개의 입력을 받아 각각의 가중치를 곱하고 편향을 더한 뒤 임계값을 거쳐 출력을 결정하는 구조입니다.

선형 회귀 (Linear Regression)

연속적인 수치 데이터를 예측하기 위해 독립 변수와 종속 변수 간의 선형 상관관계 모델을 찾아내는 대표적인 지도 학습 알고리즘입니다.

K-평균 군집화 (K-Means Clustering)

사전에 정의된 군집 개수(K)를 바탕으로 데이터들을 유사한 특성끼리 그룹으로 묶어주는 대표적인 비지도 학습 알고리즘입니다.

Part 02

인공지능 성능 평가 개념 및 지표 용어

정밀도 (Precision)

모델이 참(Positive)이라고 예측한 전체 결과 중에서, 실제로 참(Positive)인 데이터가 차지하는 비율입니다. (오탐지, 즉 거짓 양성인 FP를 줄이는 것이 중요할 때 강조되는 지표입니다.)

재현율 (Recall / 민감도)

실제 참(Positive)인 전체 데이터 중에서, 모델이 참(Positive)이라고 올바르게 맞춘 비율입니다. (실제 양성을 놓치는 미탐지, 즉 거짓 음성인 FN을 줄이는 것이 중요할 때 강조되는 지표입니다.)

정확도 (Accuracy)

전체 예측 데이터 개수 중 모델이 정답을 맞춘(참 양성 및 참 음성) 전체 비율을 뜻합니다. 다만 데이터의 불균형이 심할 경우 모델 성능을 왜곡할 위험이 있습니다.

F1 스코어 (F1 Score)

정밀도와 재현율의 상호 절충(Trade-off) 관계를 보완하기 위해 두 지표의 조화 평균을 구하여 산출하는 종합적인 성능 평가 지표입니다.

상호 절충 (Trade-off)

한쪽 지표(예: 정밀도)를 높이려 하면 다른 쪽 지표(예: 재현율)가 낮아지기 쉬운 역상관 관계를 의미합니다.

참 양성 (TP, True Positive)

실제 참인 것을 모델이 참이라고 올바르게 예측한 경우입니다.

거짓 양성 (FP, False Positive / 제1종 오류)

실제 거짓인 것을 모델이 참이라고 잘못 예측한 경우(오탐)입니다.

거짓 음성 (FN, False Negative / 제2종 오류)

실제 참인 것을 모델이 거짓이라고 잘못 예측한 경우(미탐)입니다.

참 음성 (TN, True Negative)

실제 거짓인 것을 모델이 거짓이라고 올바르게 예측한 경우입니다.

ROC 곡선 (Receiver Operating Characteristic Curve)

이진 분류 모델의 임계값(Threshold) 변화에 따른 성능 변화를 시각화하기 위해 X축에 위양성률(FPR)을, Y축에 진짜양성률(TPR, 재현율)을 놓아 그린 곡선입니다.

AUC (Area Under the ROC Curve)

ROC 곡선 아래의 면적을 뜻하며, 값이 1에 가까울수록 분류 모델의 전반적인 예측 성능이 우수함을 나타냅니다.

매크로 평균 (Macro Average)

다중 클래스 분류 문제에서 각 클래스별 성능을 데이터 개수의 비중과 상관없이 동일한 비중으로 단순 평균 내어 구하는 평가 방식입니다.
